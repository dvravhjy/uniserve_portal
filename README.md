UniServe - Integrated School Management & Student Portal

> A modern, role-based web application designed to streamline student enrollment queuing, clearance workflows, grade viewing, and administrative document requests.

Key Features

- Student Portal: View grades, track digital clearance status, and submit document requests online.
- Registrar & Cashier Dashboards: Manage student records, approve document requests, and track fee status.
- Role-Based Access Control (RBAC): Secure JWT authentication tailored for Students, Registrars, Cashiers, and Administrators.
- Modern UI/UX: Responsive interface built with React, Vite, and Tailwind CSS 

---

Tech Stack

Layer        | Technology 
Frontend     | React, Vite, Tailwind CSS, Lucide React Icons 
Backend      | Node.js, Express.js 
Database     | SQLite (Development) / PostgreSQL (Production) with Sequelize ORM 
Auth         | JSON Web Tokens (JWT) & Passwords hashed with bcrypt
